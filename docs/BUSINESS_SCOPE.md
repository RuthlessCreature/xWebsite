# 珠海小度智能科技有限公司 — 官网业务范围 v1.0

更新日期：2026-09-29

## 1. 公司对外定位

珠海小度智能科技有限公司定位为面向工业场景的智能化与数字化解决方案提供商，围绕人工智能、机器人、机器视觉、自动控制与工业软件，为客户提供从需求分析、方案设计、系统集成到部署交付、运维优化的完整技术服务。

官网主叙事统一为：

**工业智能化 · AI 软件 · 机器人自动化 · 机器视觉 · 智能制样/化验 · 数字化平台**

## 2. 官网确认纳入的业务

### 2.1 工业智能化系统集成
- 工业现场需求分析与技术方案
- 软硬件系统集成
- 自动控制、设备联动与数据闭环
- 项目实施、调试、验收、培训与运维

### 2.2 机器人自动化
- 机器人上下料、搬运、装配
- 机器人自动制样与实验室自动化
- 工作站集成、节拍设计、安全联锁
- 自动化单元与产线协同

### 2.3 机器视觉与三维感知
- 缺陷检测
- 尺寸测量
- 定位、姿态识别与机器人引导
- OCR、条码/二维码识别
- 2D/3D视觉方案集成

### 2.4 智能制样与自动化验
- 大宗物料/煤炭制样环节自动化
- 破碎、缩分、封装、转运等流程协同
- 样品流转与身份追溯
- 自动化验流程与数据闭环
- 系统运行维护与持续优化

### 2.5 工业 AI Agent 与知识应用
- 企业知识库
- 工艺/设备知识问答
- 需求解析与辅助方案生成
- 运维诊断与故障辅助
- Agent、Workflow、工具调用等工业AI应用

### 2.6 数字孪生与工业数据平台
- 设备与产线状态可视化
- 质量追溯
- 生产与项目数据看板
- 告警、趋势与效率分析
- 多系统数据集成

## 3. 官网可展示但需避免夸大的能力

- 百万元级复杂项目的实施与交付能力
- 从方案设计、软硬件集成到现场调试、验收、培训、运维的全流程服务能力
- 工业AI、机器人、视觉、控制、数据平台的跨专业协同能力

涉及具体合同金额、客户名称、项目数量、性能指标、专利、资质、认证等内容，只有在已有可公开证明材料时才对外发布。

## 4. 暂不作为官网主业务的方向

以下方向目前不作为珠海小度企业官网主营业务展示，避免品牌失焦：

- 签证、外教、人力中介等个人/独立品牌业务
- 餐饮、饮料、线下零售门店
- 楼盘活动、儿童英语活动等线下运营项目
- 未明确归属于珠海小度公司的外贸项目
- 尚未确认公司归属或商业化状态的垂直AI项目

## 5. 内容原则

1. 不把技术概念堆成“AI万能公司”。
2. 不虚构客户Logo、资质、专利、营收、团队规模、案例数据。
3. 不使用无法证明的“行业第一”“领先”“唯一”等绝对表述。
4. 重点体现工程交付、系统集成、工业场景理解与长期运维。
5. 所有新增业务必须先判断是否与“工业智能化主线”一致。
