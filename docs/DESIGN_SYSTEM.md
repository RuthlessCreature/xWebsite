# 企业官网设计系统 — 国企稳健商务适配版

来源模板：`UI-Templates/enterprise/soe-steady-business-a`

## 设计目标

将“国企稳健商务”的正式、可信、高信息密度语言应用到企业官网，而不是机械照搬 OA/审批后台。

## 基础 Token

- Canvas: `#EEF2F5`
- Surface: `#FFFFFF`
- Surface Alt: `#F4F6F8`
- Border: `#CCD4DB`
- Text: `#253544`
- Muted: `#70808E`
- Accent: `#315D78`
- Accent Strong: `#25465A`
- Radius: `4px`
- Font: `system-ui, -apple-system, Segoe UI, Noto Sans SC, sans-serif`

## 官网适配规则

- 顶部导航：白底、细边框、固定导航，避免透明悬浮和炫光。
- 首屏：左侧价值主张，右侧“能力矩阵/交付状态”式信息面板。
- 业务卡片：小圆角、细边框、轻层次；不使用大面积渐变玻璃拟态。
- 数据表达：使用编号、状态条、流程节点、技术标签建立工程可信感。
- 动效：只做轻微进入、hover、数字/流程状态变化；禁止无意义粒子背景。
- 图片：首版尽量不用廉价图库，优先采用结构化图形、线框、能力矩阵。
- 响应式：375px、768px、1024px、1440px 均需可读；移动端不横向滚动。

## 信息层级

L1：公司定位、主营方向、项目合作入口  
L2：六大业务、典型场景、工程能力  
L3：交付流程、技术标签、公司介绍  
L4：版本、版权、辅助信息

## 验收

- 3 秒内看明白公司是做什么的。
- 首屏不出现空泛“赋能未来”“智启新纪元”等套话。
- 任何一屏最多一个主诉求。
- 文案与图形在灰度下仍能辨认层级。
- 375–1440px 无明显布局崩坏。
